# The Oathkeeper

**Role:** Knight  
**Badge:** EK  
**Sigil:** ⚖

## Victory
The King wins the game. When there is no King, you lose the game if face down.

## Announce
(Trigger) When a player reveals a Bandit card to win, if that player killed the last King, turn The Oathkeeper face up. Bandits cannot win while The Oathkeeper is in the game. When no Bandits remain: if you caused the last Bandit to lose — you win. Otherwise, you lose.
