# Expanded Kingdoms Start of Game Card

**Role:** Rules  
**Badge:** EK  

## Start of Game
1. Select role cards for the player count.
2. Give the King card to a chosen or random player (face-up).
3. Deal remaining roles face-down.
4. All players close eyes. Bandits open eyes, identify each other, close eyes.
5. Begin the game — starting player is the King.
