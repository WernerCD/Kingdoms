# Game Setup

**Role:** Reference  
**Badge:** AK

## Victory
The game ends when any role's Victory condition is met.
Reveal all role cards at game end.

## Announce
Flip your card face-up to use your Announce ability (once per game, unless otherwise specified).
Some abilities trigger on Announce — these are used immediately when the trigger condition is met.

## Special
**Setup:** Shuffle role cards face-down and deal one to each player.
The King's card is always kept face-up.
Bandits secretly identify each other at game start (all players close eyes; Bandits open eyes, identify teammates, then close eyes).
All other roles begin face-down.
