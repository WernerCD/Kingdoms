# Expanded Kingdoms Card Reference

This doc maps the old **Expanded Kingdoms** (Cockatrice) card art and roles to the current **Advanced Kingdoms v1.56** cards.

## Role Mapping (Old → New)

| Old Role | Old Color | New Role |
|----------|-----------|----------|
| Bandits  | Red border | **Assassins** |
| Nobles   | Blue border | **Bandits** |
| Renegades | Black border | **Renegades** (same) |
| Knights  | Green border | **Knights** (same) |
| King     | —          | **King** (same) |

> Nobles had to kill Assassins first, THEN the King — same order as current Bandits, but without knowing teammates.

## Cards Without Art Matches (Old Expanded Kingdoms Only)

These cards existed in the old set but have no direct equivalent in v1.56:

**Old Knights (no current match):** The Bastard, Black Knight, Kingsguard, Oathkeeper

**Old Assassins/Bandits (no current match):** The Burglar, Dragonkeeper, Pirate, Slaver, The Assassin, Illusionist, Princess, Spymaster

**Old Renegades (no current match):** The Executioner, The Imposter
